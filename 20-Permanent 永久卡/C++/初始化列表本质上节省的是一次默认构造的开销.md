# 命题：初始化列表本质上节省的是一次默认构造的开销
## 定义 / 结论
https://chatgpt.com/c/68e7784f-1d20-8322-974b-cabda998073f
在构造函数内进行初始化。
m_Vector = vector;
是做了两件事情， 第一件事情就是做了 Vector3 m_Vector的默认构造；
第二件事情是做了 m_Vector = vector的拷贝。

而
特别需要注意 **const修饰词，引用成员，无默认构造成员**，只能使用初始化列表。
## 机制 / 因果
默认的构造其实就发生在**进入构造函数体之前**，会对子对象进行初始化，
当没有提供某成员的初始化器的时候。
初始化列表就是告诉编译器不要用默认构造， 用我指定的这个构造函数（拷贝/移动/值初始化/普通），所以能避免一次默认构造

## 操作 / 代码要点
```cpp
#include <initializer_list>
#include <iostream>
struct Vec {
    int x{0};
    // ① 普通构造
    explicit Vec(int v) : x(v) { std::cout << "ctor(int)\n"; }
    explicit Vec(double v) : x((int)v) { std::cout << "ctor(double)\n"; }
    // ② initializer_list 构造
    Vec(std::initializer_list<int> il) {
        std::cout << "ctor(initializer_list)\n";
        if (!il.size()) x = 0; else x = *il.begin();
    }
    // ③ 拷贝/移动构造
    / 就看传的是左值还是右值
    Vec(const Vec& rhs) : x(rhs.x) { std::cout << "copy-ctor\n"; }
    Vec(Vec&& rhs) noexcept : x(rhs.x) { std::cout << "move-ctor\n"; }
    // ④ 默认构造
    Vec() { std::cout << "default-ctor\n"; }
};

```
