## classA(x) 和 classA{x}；的区别：
前面走的是构造初始化、 后面走的是初始化列表
<font color="#ff0000">根本区别是{} 多了一个窄化检查， 以及{} 会优先匹配initializer_list</font>

```cpp
struct S {
    S(int);                            // 普通构造
    S(double);                         // 普通构造
    S(std::initializer_list<int>);     // 列表构造
};

S a(1);        // 选 S(int)
S b{1};        // 选 S(initializer_list<int>) —— 因为列表初始化优先 ilist
S c{1.0};      // 不能构造 initializer_list<int>，退回匹配 S(double)
S d{1,2};      // 只能选 ilist 版本

```
{}看起来可以初始化一串内容，因为它的input有多个。
走的也是匹配机制， {} 先匹配符合的initlist， 不行的话就匹配对应的构造函数

```cpp
std::vector<int> v1(3, 7); // 3 个元素，每个是 7
std::vector<int> v2{3, 7}; // 元素列表：两个元素 3 和 7
```

### 窄化
列表初始化禁止窄化转换（narrowing）。常见被拒绝的情况：
浮点 → 整数（double 到 int）
大整数 → 小整数（可能溢出）
整数 → 枚举（非范围内值）
任意需要丢信息的隐式转换
就是防止有些隐式转化产生，可能会在过程中造成一些信息的丢失，导致初始化错误
```cpp
int a(3.14);     // 允许（会截断，通常报警告）
int b{3.14};     // ❌ 编译错误：narrowing
char c{512};     // ❌ 可能溢出

```
## 聚合初始化：
聚合初始化就是可以一次性初始化多个元素， 比如vector的初始化。


### 默认/值初始化差异
- `T x{};` —— **值初始化**（内置类型**清零**；类类型调用**默认构造**）
- `T x;` —— **默认初始化**（内置类型**不初始化**，值不定；类类型同样调**默认构造**）
- `T x();` —— **最可恶的解析**：这是在**声明函数**，不是构造对象
```cpp
T x{};
T x;     // 默认初始化 x里面的内容值
T x();   // 注意，最后这个是在声明一个函数，
```
