## Constexpr基本概念
**Constexpr** 主要指编译器就完成的计算或者已经定义的内容，可以用作表达变量或者表达函数。
constexpr int size = 100；
则size在编译器就可以确定下来， 所以后续可以用 
int array[size];这种方式来声明一个array
而 const int size = 100；
则不一定能有这样子的效果，取决于编译器，

constexpr用作函数，表示编译器就可以得到结果的函数计算。
```cpp
// 编译期可计算的函数 
constexpr int factorial(int n) { return n <= 1 ? 1 : n * factorial(n - 1); }

constexpr int val = factorial(5); // 编译期计算 = 120 int arr[factorial(4)]; // ✓ 可以，编译期就是24

int x = 5; int result = factorial(x); // ✓ 也可以运行时调用
```
这样子比如val，在编译器就可以得到值。
val的值在编译器得到，但是如果想使用 int array[val] ，则还需要要求 val也是constexpr或者const
在C++14之前， constexpr只能有一个return语句， C++14之后可以有循环和多个语句。

constexpr还可以用作成员函数和构造函数，原理也是差不多，表示在编译期就可以确定下来的值和对象
